Melder (AI Spreadsheet Assistant)

What they do: Provides AI-powered assistance for working with spreadsheets and analyzing structured data.

Solves one problem well: Helps users work with spreadsheet data more efficiently.

Access to customers: College students, researchers, small businesses, and analysts who regularly work with spreadsheets.

Familiar infrastructure: CSV parsing, Python data processing, formula evaluation, and spreadsheet libraries such as Pandas.

LLM & Validator: The LLM explains potential spreadsheet errors and recommends corrections. The validator independently recalculates supported formulas, checks for inconsistent calculations, and compares results against expected values. If a discrepancy is found, it flags the affected cells instead of automatically accepting the LLM's recommendation.

Deployable: A web application where users upload CSV files and inspect flagged issues.

One Core Feature to Reimagine: A Spreadsheet Formula Consistency Checker. The system detects inconsistent formulas across rows, suspicious references, and calculation errors. For example, if one row calculates a total using the wrong column, it flags the issue and explains the expected calculation.
