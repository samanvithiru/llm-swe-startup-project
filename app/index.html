1. Load a routine

Use a 2D Sway PDF with named dancer markers. You'll review the extracted formations before they load. Scans and screenshots aren't supported yet.

Advanced: routine JSON

Use positive stage dimensions, named formations, and unique dancer IDs with numeric x/y coordinates inside the stage. Coordinates use stage units; y increases downward.

{
  "stage": {"width": 10, "height": 6},
  "formations": [{
    "name": "Opening",
    "dancers": [{"id": "A", "x": 2, "y": 3},
                {"id": "B", "x": 5, "y": 3}]
  }]
}
